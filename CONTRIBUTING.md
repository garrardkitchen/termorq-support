# Contributing to Termorq Support

Thanks for helping make Termorq better! This is a **support repository**, not the app's source code. The most useful contributions are clear bug reports and well-explained ideas.

## Before you open an issue

- **Search existing issues** (open and closed). If yours already exists, add a 👍 or a comment with new details rather than opening a duplicate.
- Check the [docs](https://termorq-docs.garrardkitchen.com/) — the answer may be there.

## Writing a good bug report

Use the **Bug report** template and include:

- Your Termorq version and edition (Free, Trial, or Pro)
- Your operating system and version
- The smallest set of steps that reproduces the problem
- What you expected, and what actually happened
- Redacted logs or screenshots, if they help

## Writing a good idea

Use the **Idea (feature request)** template and focus on the **problem** first: what you're trying to do and what gets in the way. Then describe the change you'd like and any alternatives you've tried.

## Keep it safe

- **Never post secrets, credentials, tokens, private prompts, or personal data (PII).** Redact everything before you post.
- **Security vulnerabilities** must be reported privately — see [SECURITY.md](SECURITY.md).

## Pull requests

Pull requests are welcome **only for this repo's own content**: the README, issue templates, and community files. The Termorq application code lives elsewhere and is not accepted here.

## Be respectful

Everyone participating is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
