# Security Policy

## Scope

This policy covers **Termorq, the published application** — Microsoft Store packages and installers — including its Free and Pro editions. It does not cover the Markdown and templates in this support repository.

Third-party services and dependencies are outside our direct control; please also report issues in them to their own maintainers.

## Supported versions

Security fixes are generally made against the latest released version. If you use an older release, update to the latest version (the Microsoft Store does this automatically) before reporting where possible.

## Reporting a vulnerability

**Please do not report suspected vulnerabilities in public issues, discussions, or pull requests.**

Report privately using GitHub's private vulnerability reporting on this repository:

<https://github.com/garrardkitchen/termorq-support/security/advisories/new>

If private vulnerability reporting is unavailable, contact the maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/garrardkitchen).

Please include:

- A description of the issue and its potential impact
- The Termorq version and edition (Free, Trial, or Pro) and your operating system
- Reproduction steps or a proof of concept

Redact real credentials and personal data; use test values in examples.

## What to expect

You can expect an acknowledgement within seven days. We will assess the report, coordinate a fix and disclosure with you, and let you know if we cannot reproduce or address it. Please allow reasonable time for a fix before public disclosure. We may not be able to provide a resolution timeline.
