# Termorq Support

Welcome! This is the public home for **Termorq** support, bug reports, and feature ideas.

Termorq is available from the Microsoft Store: **[Get Termorq](https://apps.microsoft.com/detail/9n4wvw3sq6ks)** — Free, with an in-app upgrade to Pro.

📖 **Docs:** [https://termorq-docs.garrardkitchen.com/](https://termorq-docs.garrardkitchen.com/)

## Who this repo is for

**Pro (paid) customers and active Trial users** — use [Issues](https://github.com/garrardkitchen/termorq-support/issues) for support: bugs, how-to questions, and account or licence problems after a purchase or trial. Pro customers get support priority.

**Free users** — you're very welcome here too. Suggest features and report bugs that affect Free. Support priority goes to Pro customers, but every report is read.

> **AI content concerns:** the in-app **Report an AI issue** option still goes to email, as before. This repo is for product support.

## Open an issue

1. [Search existing issues](https://github.com/garrardkitchen/termorq-support/issues?q=is%3Aissue) first — someone may have asked already.
2. [Open a new issue](https://github.com/garrardkitchen/termorq-support/issues/new/choose) and pick a template:
   - **Bug report** — something isn't working as expected.
   - **Idea (feature request)** — a new feature or an improvement.
3. Never post secrets, API keys, tokens, or personal data. Redact logs and screenshots before you attach them.

Found a security vulnerability? Please don't open a public issue — follow [SECURITY.md](SECURITY.md).

## About this repo

The Termorq application source lives in a separate, private repository. This repo holds **support only** — issues, ideas, and community docs. It does not accept contributions to the app itself.
